# 이강인 키우기 · Project KANG-IN v0.5

모바일에서 즐기는 축구 육성게임입니다. 밝은 클럽하우스 화면, 잉크색 선수 카드, 라임 포인트와 작은 도트 캐릭터를 담았습니다.

[바로 플레이](https://hanlok007-stack.github.io/project-kang-in/)

6~17세는 한 번에 1년, 18~19세는 6개월씩 빠르게 성장합니다. 20세부터는 2021~2023년의 세 시즌을 한 달씩 플레이합니다. 프로 진로는 총 52회 진행이며 방송·일상 진로는 19세에서 마무리됩니다. 각 기간에는 대표 경기 한 번만 기록합니다.

활동 10종, 이야기 사건 62개, 진로 결과 5종. 추천 계획과 이전 계획 버튼, 3개 시즌 목표, 경기 판단, 부상·회복, 역할 기반 관계와 누적 도감이 있습니다. 능력 성장은 프로가 된 뒤 완만해지고 상대 수준은 시즌마다 높아집니다.

자동·수동 저장과 JSON 가져오기/내보내기를 지원합니다. v0.3 저장은 기록·능력·난수·도감을 보존하여 가져오며 원본 v1 브라우저 저장 키는 유지합니다. 이전에 프로 진로로 끝난 저장은 '이 인생으로 프로 시즌 계속'을 눌러 이어갈 수 있습니다.

## 개발

Node.js 22.13 이상에서 실행합니다.

```sh
npm ci
npm run dev
npm run typecheck
npm test
npm run build
```

모바일 정적 빌드는 portable-dist/에 생성됩니다. GitHub Pages는 main 브랜치의 docs/를 게시합니다. 수정 후 npm run build:pages로 docs/를 다시 만들고 함께 커밋하세요.

## 구조

- app/: 터치 화면과 홈 화면 설치 안내
- engine/: 상태 전이, 시간표, 성장·경기·시즌, 저장 검증
- data/: 활동·인물·사건 데이터
- public/: 도트 캐릭터, 앱 아이콘, 오프라인 서비스 워커
- portable/: 정적 앱 진입점
- docs/: 게시 가능한 모바일 PWA 빌드
- tests/: 전체 커리어·단계별 저장·확률·오프라인 검증

## 검증과 범위

75회 커리어 시뮬레이션과 별도 3,235개 단계 검사, 실제 v1 저장 19개 호환 검사를 통과했습니다. 브라우저 모바일 UI와 PWA 업데이트도 확인합니다. 재미와 실제 플레이 시간은 사용자 테스트가 필요한 영역입니다.

현재는 22세 세 시즌 결과까지 플레이할 수 있습니다. 은퇴까지의 커리어·대표팀·실제 역사 재현은 아직 구현하지 않았습니다. 홈 화면에 설치하는 웹앱이며 App Store/Play Store 출시 앱은 아닙니다.

팬 창작 비공식 작품입니다. 선수·구단과 관련이 없으며 사건·일정·인물·계약은 허구입니다. 도트 캐릭터는 가상의 소년입니다. 저장은 기기와 사이트 주소별로 분리되므로 이동 전 파일로 내보내세요.
